# 📊 Data Analyst Portfolio

Welcome to my Data Analytics Portfolio! This repository contains a collection of projects demonstrating my skills in Data Engineering, Business Intelligence, and Data Analytics, primarily using SQL and Python.

## 📂 Projects

### 1. [Shopee Customer & Marketing Analytics](SQL/01-shopee-customer-and-marketing-analytics)
*An end-to-end data pipeline and advanced analytics project focusing on customer behavior and marketing optimization for an active Shopee store.*
- **Tech Stack:** PostgreSQL, Python (Pandas)
- **Key Analyses:**
  - Customer Segmentation using the **RFM Model** (Recency, Frequency, Monetary).
  - Tracked **Month-over-Month (MoM)** revenue growth and Running Totals.
  - Optimized marketing spend by calculating the true **Break-even ROAS (2.22x)** after accounting for all platform fees, identifying campaigns that were bleeding money.

### 2. [Shopee Sales & Operations Analytics](SQL/02-shopee-sales-and-ops-analytics)
*A robust ETL pipeline and performance analysis focusing on store operations, seasonal trends, and conversion metrics.*
- **Tech Stack:** PostgreSQL (SQL)
- **Key Analyses:** 
  - **ETL Pipeline:** Built SQL-based staging tables and used `COPY` for bulk data ingestion and transformation.
  - Analyzed peak vs. post-season **Seasonality** and Day of Week shopping routines.
  - Calculated **Quarter-over-Quarter (QoQ) Growth** and **7-Day Moving Averages** using advanced Window Functions.
